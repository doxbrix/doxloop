## Scope and observed limitations

- Direct lifecycle support is validated for Doxbrix, MkDocs and autogenerated Docusaurus navigation. Custom coded navigation and non-Markdown native formats stop before writing and direct the user to a reviewed agent proposal.
- Screenshot limits cap approved artifacts; elapsed-time limits apply per authoring attempt. Existing already-approved plans preserve the reviewed footprint for compatibility.
- Python execution never falls back to the host. The fail-closed path and container invocation/failure cleanup passed tests. The real digest-pinned container probe passed locally and in hosted CI: fixture access works; host-file access, writes to read-only mounts, and network access are blocked.
- Separate real-agent observations are recorded for review and generation. Review detected all four seeded signals; generation completed planning, authoring, and acceptance, scoring 62/100 with 19 warnings and no quality failures. This exceeds the configured floor of 60, but does not establish publication-ready prose. The runner preserves failure diagnostics and proposal workspaces and compares only matching fixture, agent, model, mode, and reasoning settings.
- The existing checkout and index remain on `stage`. An isolated Git index was used to snapshot and push the authorized work to `codex/claude-review-follow-through` for hosted CI. No merge, release, or deployment was performed. Licensing is unchanged.
